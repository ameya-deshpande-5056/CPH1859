# Artifacts Index: Realme 1 (CPH1859) Bootloader Unlock Research

This directory indexes diagnostic outputs, collected firmware metadata, logs, and technical reports generated throughout the research.

> [!IMPORTANT]
> Large binaries (e.g., full `.ozip`, `.ofp`, or partition images) and sensitive unredacted device data must never be committed to Git. Such files must be stored locally in ignored subfolders and indexed here with checksums.

## Redaction Protocol
All text artifacts undergo regex-based sanitization before writing:
- Serial numbers -> `[REDACTED_SERIAL]`
- IMEI numbers -> `[REDACTED_IMEI]`
- MAC addresses -> `[REDACTED_MAC]`
- Android ID / Unique tokens -> `[REDACTED_ID]`
