# Artifacts Index: Realme 1 (CPH1859) Bootloader Unlock Research

## Redaction Protocol
All text artifacts undergo regex-based sanitization before writing:
- Serial numbers -> `[REDACTED_SERIAL]`
- IMEI numbers -> `[REDACTED_IMEI]`
- MAC addresses -> `[REDACTED_MAC]`
- Android ID / Unique tokens -> `[REDACTED_ID]`
